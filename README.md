An entry for the [Ship It Friday](https://make.fun/c/u-mgwals-ship-it-friday-30bd407a) competition on make.fun.

The program writes one line — the funniest git commit message an AI coding agent would write right before breaking production on a Friday — to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

It writes:

```text
feat: ship to prod on Friday — all tests passed in my head, rollback is a Monday problem
```
